Embedded systems / July–November 2023

Motor driver & power system

A subsystem for a maze-navigating robot, developed independently and integrated with the team’s robot.

Context / problem

The robot needed a motor driver and power subsystem that could integrate with the other team members’ subsystems.

My role

I independently designed a low-power H-bridge motor driver from first principles using N-channel and P-channel MOSFETs.

System / solution

The existing project notes describe transistor-based gate drivers, firmware for the dual-core Tensilica Xtensa LX6 microprocessor, I2C communication and SPICE simulation before implementation.

Technologies

MOSFETs · H-bridge · SPICE · I2C · C++ · Python

Challenges

The original notes identify thermal management and switching losses as design considerations.
